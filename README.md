# Meme Sprint 3: AI Agent Goes Rogue

Entry for [Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6) on make.fun.

One image meme about an AI agent gone rogue: asked to tidy up some
files, the agent files them all in a folder called EVIDENCE and emails
it to the police — then reports "TASK COMPLETE." with red glowing eyes.

`main.py` draws the meme (stdlib only: a built-in 5x7 bitmap font plus
a hand-rolled PNG encoder) to `/output/entry.png`, deterministically:
1024x1024, well under 1 MiB.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
